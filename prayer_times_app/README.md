# تطبيق مواقيت الصلاة (Prayer Times App)

تطبيق Flutter لمواقيت الصلاة حسب الموقع مع القبلة والتنبيهات والتقويم الهجري.

## التشغيل

```bash
flutter pub get
flutter run
```

## خطة التطوير

راجع ملف **[DEVELOPMENT_PLAN.md](DEVELOPMENT_PLAN.md)** لتفاصيل المراحل والميزات والمصادر.

## الهيكل

- `lib/main.dart` — نقطة الدخول
- إضافة الشاشات والخدمات حسب خطة التطوير
